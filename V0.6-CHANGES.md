# Our Cadence v0.6 — Mixer audition & loudness pass

This revision continues from the user's newer componentized studio branch.

## Mixer
- Added an independent play/stop button to every one of the four tracks.
- Track audition ignores the track's M/S exclusion state but keeps that track's current fader level.
- The piano roll and track state now follow both full-arrangement playback and isolated track playback.
- Per-track faders now support 0–150% instead of stopping at unity gain.
- Added a persistent master output control from 0–160% in the Sound stage.

## Loudness
- Raised the default musical balance to 100 / 74 / 82 / 62% for melody / chords / bass / drums.
- Added gentle makeup gain before the output compressor so the default mix is noticeably louder without simply hard-clipping the stems.
- WAV export uses the same master output setting as live playback.
- MIDI CC volume is clamped correctly when a track is boosted above 100%.

## Compatibility
- Existing projects with track volumes at or below 100% remain valid.
- The master volume is stored as a browser preference rather than changing the project schema.
