# Our Cadence v0.4 prototype changes

## Image analysis
- Transparent PNGs now use the alpha channel as an exact subject mask instead of treating transparent pixels as black background.
- Character cutouts no longer become false `夜景` / extremely dark images.
- Thumbnails use `contain` and a neutral checkerboard background so full-body art is not cropped or stretched.
- Opaque photos use a border-similarity + center/edge saliency foreground estimate.
- Background can explicitly be `transparent`, in which case it is excluded from scene/night calculations.

## Quick music directions
Added: 角色主题 / 轻快日常 / 回忆抒情 / 战斗电子 / 冷峻机械 / 梦幻空灵 / 黑暗悬疑 / 复古合成 / 动画 OP.
Each preset changes the Music Profile, composition defaults and online search intent.

## Sound quality
- Rendering sample rate raised to 44.1 kHz.
- Reworked electric keys, bell, pluck, pad, bass and drum synthesis.
- Added filtering, multi-oscillator voicing, better envelopes, stereo placement, master compression and algorithmic reverb.
- Accompaniment now has richer seventh chords, more musical bass patterns and four-bar drum fills.

## Online song search
- Multi-provider backend: Apple Music/iTunes catalog, Deezer, QQ Music, NetEase Cloud Music and Bilibili search attempt.
- QQ / NetEase / Bilibili are unofficial web-facing endpoints and may change or rate-limit; the UI always exposes a direct platform search link as fallback.
- Bilibili increasingly requires WBI/cookies for structured search, so its direct search link is intentionally always available.
- Search results are diversified across providers instead of relying on an embedded reference-song list.

## Launch
- `启动 Our Cadence.bat`
- `start-our-cadence.bat`
- First run installs npm dependencies; subsequent runs start the local server and open `/studio` automatically.
