# 角色卡素材来源

工作室角色卡使用 `stars.svg` 和 `music.svg`，来源为 **Tabler Icons v3.46.0**，MIT License。完整许可证见同目录 `Tabler-LICENSE.txt`。

- Stars 原件：https://raw.githubusercontent.com/tabler/tabler-icons/v3.46.0/icons/outline/stars.svg
- Music 原件：https://raw.githubusercontent.com/tabler/tabler-icons/v3.46.0/icons/outline/music.svg
- 项目：https://github.com/tabler/tabler-icons

本地版本保留 SVG 原图形路径，调整描边至 0.85 并使用浅色描边／局部填色。工作室仅复用已有素材，CSS 控制位置、透明度与短暂浮动，不增加外部运行时请求。

原共用素材目录已被另一项整理任务归档。工作室的两款实际依赖独立保存在此目录，避免与首页素材替换相互影响。
