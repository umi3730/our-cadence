# Our Cadence — Noise 参考版

参考来源：`D:/Our Cadence/noise-portfilo copy`。本轮按用户授权完整重构前端，保持音乐与存档实现。未更改参考目录。

## 保留的设计特征

- 左上角用户提供的蓝紫粉手写字标保持原样。中间恢复 `Our Cadence.`、`One theme. Many scenes.`、`Make it Your own.` 三组英文标题，取消渐变标题带，使用居中的 Inter 500 斜体与 -0.04em 字距；标题下为小字索引，中文说明和入口按钮分别放在下方两侧。
- 参考文件夹声明 Inter，但没有附带字体文件；当前将 Inter 官方可变斜体 WOFF2 及 OFL 许可放在 `public/fonts/`，页面本地加载。主标题控制在 800px 内容区内，手机端按短语换行，并将说明与按钮纵向排列；较矮桌面窗口保留完整翻页器。
- 三屏手动切换，左下圆形斜线分页器，右下仅保留章节文字索引。桌面足够高时支持滚轮，另提供按钮与左右键；内容高于窗口时保留正常滚动。
- 文字悬浮逐字上下置换，页面轻量进入动效；减少动态效果设置下禁用动画，不自动轮播。
- 工作室参考详情页三栏：左侧标题、角色与步骤；中间主题 / 场景 / 混音；右侧工程信息。当前不展示生成式人物插画。
- 首页在奶白底上加入缓慢流动的浅金色雾，保留石黑文字、灰色细线与干净的中央文字区域；工作室继续使用近白纯色底。

## 素材范围

- 使用用户提供的透明底字标 `our-cadence-wordmark.png`；人物插画 `character.png` 与 `our-cadence-hero.jpg` 暂时撤下展示，文件保留，等待后续素材。
- 不复制参考文件夹中的第三方作品图片、作者介绍、奖项或项目履历。
- 首页背景已确定为奶白 `#FBF9F3`、香槟金 `#EAD8AB`、浅杏 `#F2E5CF`，使用真实 3D simplex noise 与低频坐标扰动生成柔和色雾；三屏连续流动，不叠加颗粒，也不引入 3D 圆球画廊。
- 用户要求加强动态感后，噪声时间系数由 0.025 调至 0.12，并加入连续坐标漂移；保留后台暂停及减少动态效果模式。
- 用户选定星尘方向：首页主内容区启用小四角星与少量音符拖尾，沿用灰黑与浅金色，约一秒内淡出，不需要新增图片素材。工作室不启用拖尾。
- 星星后续调整为明亮金黄与柔和光晕，尺寸 11–19px；音符保留灰黑色。色雾位于拖尾与内容下层，不接收指针事件。

## 功能与实现

继续使用 React / TypeScript 与既有 Radix 组件，无新增运行依赖。首页进场动画用 CSS，拖尾使用 Web Animations API，限制粒子数量并在离开、切换窗口或卸载时清理；触屏与减少动态效果模式下停用。翻页使用局部状态，不影响工作室或编辑表单的滚轮和键盘行为。

保持角色设定、主题候选、主题采用、场景编曲、音色 / BPM / 混音、保存 / 恢复版本、JSON / MIDI / WAV 导出。沿用已有 localStorage 键与 schema；页面重构不重建用户的音符。
