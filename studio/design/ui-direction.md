# Our Cadence · 青春乐队手账

本次为 UI 设计及本地交互预览，未发布。用户两张参考为视觉方向，不直接复用其品牌文字或标志。

- 第一张：珊瑚粉底色、轻盈自由的手写气质、小型音乐装饰。
- 第二张：靛蓝与晴空蓝、斜向节奏线、英文手写标题。
- 画面：暖白工作台，左侧角色立绘与故事，右侧主题试听 / 场景 / 四轨控制；底部持续显示播放状态。
- 品牌色 #EC758B，深色 #414963，点缀 #6BABC9，背景 #FCFAF8。粉色大面积装饰与文字主操作区分，主按钮使用更深的 #A93350。
- 正文使用系统中文字体；英文品牌使用 Segoe Script / Segoe Print 回退，不增加外部字体请求。
- 主题选择、场景选择同时使用文字与颜色反馈。原生按钮、Radix tabs/dialog/slider；响应式折叠角色栏，保留主题选择与播放器，尊重减少动态效果偏好。

UI/UX Pro Max 已执行设计系统检索；首次结果偏黑白作品展示与滚动叙事，不符合工作区任务，未采用。按 product 域重试未找到对应结果，最终布局和颜色来自用户参考与项目需求，键盘、对比度、状态反馈沿用技能通用原则。

角色图为原创示例插画。试听复用已有本地合成器，不代表 AI 从图片生成音乐；角色插画仅作视觉展示，不上传。
