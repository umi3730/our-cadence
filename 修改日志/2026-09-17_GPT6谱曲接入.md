# 2026-09-17 GPT-6 Astra 谱曲接入

基于当前 `98d66b5` 继续开发。用户确认采用“GPT 作曲＋现有音源渲染”路线，并选择自行在本地配置 API Key。

## 已实现

- 新增 `/api/compose`，使用官方 Responses API 和固定模型 `gpt-6-astra`；严格 JSON Schema 输出后再做音乐数据校验，不执行模型输出代码。
- 输入角色故事、可选图片、音乐参数、已采用主题和当前场景；输出十六小节、四轨、四段发展的符号乐谱。
- 校验音符音高／时长／力度、拍点边界、段落起点、轨道及乐器顺序、鼓音高映射、重复音符与四段机械重复。
- 场景页新增“规则草稿／AI 编曲”切换，AI 谱曲仅手动触发，显示等待时长并可取消。失败、过期响应和取消不覆盖原作品；缺少 Key、权限／额度、模型拒绝或不完整结果有明确提示。
- AI 结果按场景保存，随草稿、版本和 JSON 工程导入导出；旧工程无 AI 字段仍可加载。输入变更后旧 AI 乐谱失效但不删除，回到规则模式。
- 已保存 AI 乐谱接入原四轨试听、单轨试听、混音、MIDI 与 WAV 导出；改速度／旋律音色时不修改原 AI 数据。
- 修复 `Number(null)` 导致首次总音量变为 0 的问题；保留用户明确保存的 0，界面提示调高音量。
- 修复候选主题试听被编曲静音／独奏状态覆盖的问题；WAV 总音量按点击导出时取快照。
- 为采样音源下载增加 8 秒超时，网络不可用时走既有合成器备用路径。
- 新增版本或替换 AI 乐谱前校验工程大小，防止生成不能再次导入的超限文件；导出使用紧凑 JSON。
