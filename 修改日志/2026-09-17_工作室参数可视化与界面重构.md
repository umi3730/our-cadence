# 2026-09-17 工作室参数可视化与界面重构

## 需求与范围

按用户指定的 ui-ux-pro-max 技能重构 `/studio` 功能界面，减少上传图片后的长篇说明，用可视化参数替代。首页不改。

从远端提交 `68357cb` 创建并检出本地分支 `feat/studio-profile-ui`；保留此前 README 和修改日志的本地更改。业务代码改动集中于 `studio/components/creation-studio.tsx`、新组件 `studio/components/studio-profile.tsx` 和 `studio/app/studio.css`。

## 界面改动

- 图片和音乐参数并排呈现；手机端改为小图摘要和下方参数区，取消占满窄屏的大上传框。
- 七项音乐参数改为可拖动、可键盘调整的横向条形图，保留数值、标签和 0–100 范围。
- 默认只展示音乐性格摘要、BPM、调式、音色倾向及少量图片标签；详细主体／背景说明、配乐线索和参数解释折叠收起。
- 九个音乐方向改为紧凑选项按钮，突出“生成主题”入口。
- 找歌区域移到主题选择之后，改为歌曲行列表；试听和匹配依据按歌曲展开，匹配数值标为“匹配分”。
- 宽屏采用侧栏加主操作区；窄屏把侧栏压缩为顶部上下文。调整场景卡片和混音触控间距。
- 缩短分析和预设切换提示；没有变更作曲算法、搜索 API 或音源。

## 与界面状态相关的修正

- 在进入异步搜索前捕获有效的音乐参数，修复此前该组件的 TS2345 类型错误。
- 已取消的搜索，其音频二次评分结果不再回写当前列表。
- 恢复版本／导入工程时清除旧图片 Object URL 的展示状态，并恢复对应的识图状态。
- 图片分析期间禁止参数、方向及主题采用操作，减少分析结果与用户操作交叉覆盖。
